# Data Dictionary

## raw_sales_campaign
- customer_id: Unique customer identifier
- customer_name: Customer name
- email: Raw email address (sensitive)
- region: Sales region
- campaign_id: Marketing campaign identifier
- spend: Campaign spend
- revenue: Revenue attributed
- converted: Conversion indicator
- event_date: Activity date

## fact_sales_kpi
- roi: Return on investment
- conversion_flag: Standardized binary conversion metric
